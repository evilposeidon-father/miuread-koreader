# Kindle 微信读书 · 整套设计方案（对齐与妥协）

> 基准：微信读书手机端 App（书架 / 书城 / 发现 / 我的 + 阅读页）。
> 原则：**能对齐就对齐，妥协尽量不妥协**——妥协只允许发生在平台（e-ink/KOReader）与服务（API/腾讯）的硬边界，且每项妥协必须有升级路径。
> 本文件是设计规格；配套：docs/weread-mobile-alignment.md（计划）、docs/weread-design-tokens.md（令牌/映射）。

---

## 1. 设计原则

1. **手机端是规格书**：所有界面以手机端结构为准，先对齐信息架构、层级、命名、操作路径，再谈视觉。
2. **原生优先，外观对齐**：KOReader 原生组件优先；原生能力可调整布局/比例的，调到与手机端一致。自绘仅限保留清单（书架封面墙、底部 Tab、阅读页顶部/底部常驻栏、hero 与时长卡）。
3. **妥协最小化**：每个妥协点必须三问——"真的做不到吗？"（API 核查/真机验证）、"有没有原生替代？"（事件映射）、"能不能部分对齐？"（结构/命名/空态先对齐）。
4. **灰阶表达**：彩色降级为灰阶时用形态区分（下划线/反白/图标实心），不损失信息。
5. **零虚假**：无 API 的功能（榜单、社区、会员）不做也不占位；靠齐项必须注明（如"本地分类"）。

## 2. 信息架构（页面树）

```
底部 Tab（常驻）
├─ 书架（默认落地）
│   ├─ 顶部：搜索入口 · 排序/编辑
│   ├─ 继续阅读大卡（最近在读 + 进度）
│   ├─ 书籍网格（3 列：封面 + 标题 + 进度角标）
│   ├─ 页内分组：已下载 · 本地书籍 · 本地分类（入口卡）
│   └─ 长按书 → 操作菜单（继续阅读/详情/移除/隐藏）
├─ 书城
│   ├─ 搜索微信读书（核心，全库；未加入书架也能下载）
│   ├─ 公众号（订阅号内容入口）
│   └─ 线上分类（待验证 API；验证前不占位，也不把本机内容伪装成书城）
└─ 我的
    ├─ 账号状态（登录/失效提示）
    ├─ 阅读时长卡（今日 + 本周）
    ├─ 我的想法 · 我的划线（聚合列表）
    ├─ 书架管理 · 阅读历史
    └─ 设置（原"觅阅设置"入口归入）

阅读页（独立层级）
├─ 顶部常驻：返回 ← · 书名 · 当前章节
├─ 底部常驻工具栏：目录 / 进度 / 字体 Aa / 亮度 / 更多
├─ 更多 → 原生菜单：书签 · 想法 · 划线 · 搜索 · 阅读设置
├─ 长按选词 → 划线 / 笔记 / 复制 / 查词
├─ 点击划线 → 想法弹层（想法 / 样式 / 颜色→灰阶形态 / 删除）
├─ 章内 / 章末想法（动态拉取）
└─ 主题三档：护眼米（默认）/ 纯白 / 夜间
```

## 3. 屏幕规格

### 3.1 书架（对齐度：A）

```
+----------------------------------------------+
| 觅阅                    ⌕搜索    ☰排序/编辑  |  顶部行（标题 + 搜索 + 排序）
+----------------------------------------------+
| [继续阅读]  封面 | 书名 | 进度条 38%  ▶     |  hero 大卡：点击继续阅读
+----------------------------------------------+
| [封面][封面][封面]                          |  3 列网格
|  书名   书名   书名                          |  封面 + 标题 + 右下进度角标（在读 x%）
| [封面][封面][封面]                          |
+----------------------------------------------+
| 公众号 ›   书单 ›                           |  入口卡（列表行）
+----------------------------------------------+
| < 书架 >  书城  我的                         |  底部 Tab
+----------------------------------------------+
```

- 对齐项：继续阅读大卡、3 列网格、进度角标、搜索位置、排序/编辑、公众号入口、空态（登录引导/去书城）。
- 实现：现有 home_view 网格 + hero 强化；排序/编辑 = 原生 TouchMenu + ConfirmBox。

### 3.2 书城（对齐度：B——搜索 A，榜单/推荐 C→本机聚合 B）

```
+----------------------------------------------+
| 书城                    ⌕搜索微信读书        |
+----------------------------------------------+
| [⌕ 搜索微信读书]                             |  A 完全对齐（核心）
+----------------------------------------------+
| [公众号 ›]                                    |  A 入口（订阅号内容）
| [封面][封面][封面]                          |
+----------------------------------------------+
| 线上分类（待验证 API）                        |  验证前不占位；不显示本机内容
| [封面][封面][封面]                          |
+----------------------------------------------+
|（空）                                         |
+----------------------------------------------+
| 书架   < 书城 >  我的                         |
+----------------------------------------------+
```

- 妥协说明：无线上榜单/推荐/分类 API（已核查代码库端点）；搜索体验完全对齐手机端。
- 评审修正（R1 产品/UX）：书城只放"搜索 + 分类 + 公众号"，**不把已下载/本地/本地分类伪装成书城**；本地聚合移回书架页内分组。
- 升级路径：线上分类/免费接口验证可用后补入（B2 升 A）。

### 3.3 我的（对齐度：B——时长/想法/划线 A，头像/会员 C）

```
+----------------------------------------------+
| 我的                                          |
+----------------------------------------------+
| [账号状态] 已登录 · 微信号/昵称（如有）      |  无头像（无用户资料 API）
+----------------------------------------------+
| 今日 1h23m   本周 8h45m                       |  时长卡（自绘）
+----------------------------------------------+
| 我的想法 ›   我的划线 ›                       |  原生列表
| 书架管理 ›   阅读历史 ›                       |
| 设置 ›                                        |
+----------------------------------------------+
| 书架  书城   < 我的 >                         |
+----------------------------------------------+
```

- 对齐项：时长卡（今日/本周，与手机端同源可对）、想法/划线聚合、书架管理、设置归入。
- 妥协：无头像/昵称/会员标识（无 API，C）；登录状态与失效提示必须有（防会话互顶困惑）。

### 3.4 阅读页（对齐度：A，夜间 B 待验证）

```
+----------------------------------------------+
| ←  书名 · 第 x 章                38%        |  顶部常驻（返回/书名/章节）
+----------------------------------------------+
|                                              |
|                正 文 阅 读 区                 |
|           （长按选词 → 划线/笔记/复制/查词）  |
|                                              |
+----------------------------------------------+
| 目录  进度   Aa  亮度  ···                   |  底部常驻五组
+----------------------------------------------+
```

- 对齐项：
  - 顶部：返回 + 书名 + 当前章节（现有工具栏顶部行对齐布局）。
  - 底部：目录 / 进度 / 字体 Aa / 亮度 / 更多 五组；搜索/书签/想法/划线收进"更多"（原生 TouchMenu）。
  - 长按选词：划线（默认下划线，已有）/ 笔记 / 复制 / 查词。
  - 点击划线 → 想法弹层（已有 thought_native_popup）：想法 / 样式（灰阶形态）/ 删除。
  - 章内/章末想法（动态拉取，已有）。
  - 进度滑杆 + 章节跳转（已有）；**e-ink 上松手生效**（不做拖动实时预览）。书签（已有）。
  - **点正文呼出/收起工具栏**（常驻栏显隐；翻页时收起避免遮挡与误触）。
  - 章内想法：**章末聚合 + 手动刷新**（弱网/慢刷新下不实时联网拉取，避免翻页卡顿；动态拉取保留但节流）。
  - 查词：无词典库时降级为"复制"，不弹空菜单。
  - 主题：**夜间 = KOReader 原生 night_mode**（快捷面板设备行/控制中心已有切换）；**纯白 = KOReader 默认正文底色**；**护眼米 = 面板皮肤靠齐**（cre 正文底色 KOReader 无用户级设置，用米色卡片/色温/前光表达；正文底色不可改，见 §6 能力边界）；亮度走前光原生控件。
- 妥协/待验证：
  - 夜间正文反白：先验证 KOReader 阅读主题支持度；不支持则背景 + 前光 + 系统反转（B）。
  - 目录/字体面板：先逐个映射 KOReader 原生事件（TOC/字体菜单）真机验证（4.5.43 复检）；不可达则自绘（外观对齐）。

| --- | --- | --- | --- |
| 书籍详情 | 简介/作者/分类/进度/加入书架/开始阅读 | 打开书籍弹层（已有 _show_home_book_open_popup）信息结构对齐 | A |
| 批注弹层 | 想法 + 评论数 + 样式/颜色/删除 | thought_native_popup（已有） | A |

| 登录 | 扫码/手机号 | 扫码流程（已有） | A |

### 3.6 状态页（空态/加载/错误/离线）

- 空态：文案与手机端一致（"书架空空，去书城看看吧"等），附主操作按钮（搜索/去书城）。
- 加载：e-ink 无动画 → 文案 + 进度提示（已有 status_toast），不模拟转圈。
- 错误：原生 InfoMessage + 重试入口；网络/登录错误区分提示。
- 离线：下载完成的书籍可离线读（已有）；未下载书籍显示"需联网下载"。
- 搜索无结果：手机端同款空态（"没有找到相关书籍"）+ 换关键词提示。
- 会话中途失效（翻页 401）：静默续期，失败后一次性提示重新扫码（不打断阅读）。
- 下载失败/磁盘满：原生错误提示 + 重试；磁盘满给清理引导。
- 本地分类为空：不显示空分类入口。
- 查词无词典：降级为"复制"，不弹空菜单。

## 4. 全局交互规范

- **层级**：Tab（书架/书城/我的）→ 页内操作 → 弹层/菜单 → 原生对话框；返回键逐层回退（子页 → Tab 根 → 退出首页）。
- **点封面 = 直接阅读**（未下载先走下载确认）；**长按 = 操作菜单**；**书名/长按 = 进入详情**。
- **手势**（KOReader 体系，不硬套手机触屏）：点按 = 确认；长按 = 上下文菜单；滑动 = 翻页；边缘 = 防误触翻页（已有）；顶部下滑 = 快捷面板（保留）。
- **触控目标**：≥ 48px 等效；Tab 高 56px；工具栏按钮 ≥ 48px。
- **反馈**：Toast 短提示；操作成功不弹框（无感）；失败必提示 + 可重试。
- **一致性**：同一操作全局同一入口（如"设置"只出现在"我的"）；文案术语统一（书架/书城/我的/想法/划线/继续阅读/阅读时长）。

## 7. 妥协最小化策略（尽量不妥协）

1. **每个 B/C 项先做"三问"再定级**：API 核查（书城分类/免费接口）→ 真机验证（夜间反白、目录/字体事件直达）→ 结构对齐兜底（命名/层级/空态先对齐）。
2. **B 项都要有升级路径**：B2/B5/B6 在本计划 P1/P3 内真机验证，能升 A 就升 A。
3. **C 项只允许发生在硬边界**：e-ink 物理（动效/彩色/手势）、腾讯服务（会员/社区/听书）、无 API（榜单/头像）。
4. **外观对齐优先级**：结构 > 命名 > 空态 > 视觉；视觉对齐仅在灰阶内做到位。
5. **拒绝"差不多"**：对齐项要有验收截图对照（真机走查时逐项拍屏对比手机端）。

## 8. 待验证清单（决定 A/B 边界）
