# 阅读器 UI 决策（MiuRead 4.5.42 → 4.5.43 回滚）

## 结论（4.5.43）

**保留 MiuRead 自绘面板为默认**。4.5.42 曾尝试把「目录/字体/进度/书签」等 8 个面板
委托给 KOReader 原生菜单，但真机反馈：原生菜单能弹出，却不会跳转到对应面板、不能
直接修改，体验突兀。因此 4.5.43 回滚为自绘面板。

## 回滚记录

- 4.5.42：新增 `reader_ui.panel_mode`（默认 `"native"`），8 个面板方法委托
  `_show_koreader_reader_menu`（通用 KOReader 顶部菜单）。
- 真机反馈：通用菜单无法直达具体设置项，比自绘面板更难用。
- 4.5.43：移除 panel_mode 与委托守卫，恢复自绘面板直接调用。

## 为什么暂不委托原生

KOReader 原生的「目录/字体/进度/书签」各自有独立事件（而非通用菜单）。要正确委托，
需要逐个面板映射到对应事件并真机验证；在无真机验证前，通用菜单路由是错误实现。

## 后续（若再次尝试）

1. 逐个面板映射到 KOReader 具体事件（目录/字体/进度/书签各自独立入口）。
2. 真机验证每个按钮直达对应面板且可修改。
3. 通过后以 `reader_ui.panel_mode`（默认 `"miuread"`，可选 `"native"`）灰度上线。
