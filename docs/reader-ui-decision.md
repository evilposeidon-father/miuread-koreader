# 阅读器 UI 决策（MiuRead 4.5.42）

## 决定

阅读器设置/排版类面板**默认委托给 KOReader 原生菜单**，仅保留 MiuRead 差异化内容
（云划线、想法、同步、书籍信息等）。

- 默认 `reader_ui.panel_mode = "native"`：目录、进度、字体、间距、书签、页面显示等
  与 KOReader 原生能力重复的面板，改由「KOReader 高级菜单」承载。
- 用户可在设置中切回 `"miuread"`，继续使用 MiuRead 自绘的 WeRead 风格面板。

## 背景

MiuRead 内置了一套约 5,752 行的阅读器 UI（toolbar/控制中心/设置/排版/前光/进度/
目录/书签等），与 KOReader 原生 top/bottom 菜单大量重复。保留它是为了 WeRead 风格
外观，但长期维护成本高。

## 边界

- 保留：快捷面板/工具栏壳、云划线/想法、静默同步、当前书籍、评论设置等 WeRead 专属能力。
- 委托：设置、排版（字体/间距/页边距/页面显示/刷新）、前光、进度、目录、书签列表。

## 迁移路径

1. 4.5.42：加入 `panel_mode` 开关，默认 `"native"`，8 个面板方法委托原生菜单。
2. 后续：真机验证后，逐步删除 `"miuread"` 模式下已无调用方的自绘面板模块。
