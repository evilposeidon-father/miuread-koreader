# Kindle 微信读书 · 设计令牌与原生组件映射（P0）

> 以微信读书手机端为基准，把手机端设计语言降级为墨水屏灰阶表达，并把每个界面元素映射到 KOReader 原生实现。
> 规则：**凡 KOReader 原生能做的，一律原生；自绘仅限保留清单。**

## 3. 间距与网格规格（Kindle PaperWhite 3 基准：6 寸 758×1024 @150dpi）

- 页面边距：16px；卡片间距：8px；卡片内边距：12px。
- 书架网格：3 列封面（封面宽 ≈ (屏宽−32−16)/3 ≈ 236px，高 ≈ 1.42×宽）；与手机端 3 列网格同构。
- 底部 Tab 栏：高 ≈ 56px，三 Tab 均分（书架/书城/我的），选中态 = 实心图标 + 加粗文字。
- 阅读页顶部栏高 ≈ 40px，底部工具栏高 ≈ 56px。
- 卡片圆角：2px（e-ink 上大圆角无意义，克制）。

## 4. 自绘保留清单（仅这些允许自绘，其余一律原生）

1. 书架封面墙 + 网格 + 进度角标（KOReader 无此组件）
2. 底部三 Tab 栏（KOReader 无原生 TabBar；用现有 category_tabs 改造）
3. 阅读页顶部常驻栏（返回+书名+章节）与底部常驻工具栏（五组）——阅读中常驻，原生菜单无法承担
4. 「继续阅读」hero 卡、「我的」时长卡（卡片式自绘组合，内部按钮/菜单走原生）

## 6. 能力边界（必须在实现前确认）

- KOReader 阅读主题：正文反白（夜间）依赖 KOReader 对阅读背景/文字色的支持程度；做不到时夜间 = 背景 + 前光补偿 + 系统反转，标注为"靠齐"。
- 目录/字体面板委托：4.5.42 已失败一次，P3 必须逐个映射具体事件并在真机验证后默认启用；不可达则保持自绘。
- 书城分类：仅本地元数据 category 分组（无线上分类 API），页面注明"本机分类"。

## 7. 验收规则

- 每个新界面元素必须有 §5 映射行；无映射 = 不做或靠齐，禁止临场自绘新组件。
- 自绘组件必须命中 §4 保留清单，否则改用原生。
- P1–P5 每期结束跑 Lua 套件（当前 245）+ 结构守卫（24）回归。
